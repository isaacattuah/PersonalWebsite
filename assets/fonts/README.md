# Fonts

Self-hosted so the site makes no third-party font requests. Latin subsets, WOFF2,
taken from the Fontsource distributions. All are licensed under the SIL Open Font
License 1.1 (https://openfontlicense.org).

- Bricolage Grotesque (variable: weight, optical size). Copyright The Bricolage Grotesque Project Authors.
- Source Serif 4 (variable: weight; roman and italic). Copyright Adobe.

Fonts used only by the design prototypes live in `demos/fonts/`:
Archivo (Omnibus-Type), Newsreader (Production Type), IBM Plex Sans and IBM Plex Mono (IBM). Same license.
