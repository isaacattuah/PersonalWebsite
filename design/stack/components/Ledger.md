# Ledger

A short table that pairs a figure with what it counts. Used for the reach of Isaac's enablement work.

- A real table: the figure is a row header (`th scope="row"`), the description is the cell.
- Figure in the sans face at weight 700, 32px, `green`, with tabular numerals. It does not wrap.
- Description in `body`, starting lower-case when it continues the figure as a sentence ("550+ attendees at...").
- Rows are separated by a 1px `line` rule. Five rows at most; beyond that it stops being scannable.
- Figures must be public-safe: people reached, hours, cost removed. Never sales figures.

You provide: each figure and one sentence saying what it counts.
